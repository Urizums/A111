# C1 analysis, declared before business-result collection

Selected denominator: eight workers, four A/B pairs. Keep every sample and mismatch in the main table. A failed/nonconforming pair remains visible with its reason; never replace it or silently merge it into a successful-only speed comparison. The method-review may propose findings; Root recomputes them against the frozen clause and originals.

Primary descriptive observation is worker_reply span plus coordinator decision span, because those are the stages whose scaffold construction changes. Report both spans separately, their sum, signed B-minus-A seconds and B/A only when finite positive and both treatments have the required original capture/source acceptance. Show individual pairs before any medians/ranges. With four pairs, no inferential/global speed claim is supported. Differential assistance/treatment drift is visible and may invalidate that efficacy comparison while preserving source outcomes.

Secondary observations: worker_work, coordinator setup/receive/review/commit, sample setup-begin to commit-end, captured subprocess count/elapsed, draft/preflight calls, native creates/queries, waits, nonzero exits/correction classification and missing/direct-write captures. Stage spans include actor thinking, file operations, tool calls and waits inside their markers. They cannot be subtracted from wall time to produce active model time; unmarked gaps and the shared intake/instrumentation remain separate. CLI elapsed is only local subprocess elapsed, not tool round-trip cost.

Check monotonic boot identity, exactly one begin/end per required actor/stage, nonnegative order, worker preflight ending before worker_reply end and the recorded actual completed native snapshot import, decision preflight before original commit, and actual replies/checkpoints/evidence SHA. Native observer timestamps are before-call intents/after-return imports, not authenticated provider timing. Requested model settings differ from verified internal identity; tokens/cost stay null absent actual telemetry.
