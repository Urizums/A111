# R22 独立首判计划

接收只按已冻结的 h1–h6。原材料曾被使用，这是知情历史策略回放。prepared source 与本计划先锁定，再进行任何结果重建。实际模型、token、费用没有可验证数据时保留 `null`。所有执行命令使用仓库 `scripts/record_command.py`，收据保留实际 argv、终态、起止时点及完整 stdout/stderr；产生作者结果的原始流仅作为操作证据，不能作数值答案。

## 证据顺序

1. **身份和执行完整性（h5）**：核验 R22 协议锁、R21输入锁、R21允许的来源锁身份、R22 execution-lock 和 source-delivery-lock 中获准文件的 SHA/长度。阅读 execution receipts 时只抽取命令 argv、终态码、实际起止时点和流是否完整；若原始 stdout 包含作者结论/数值，不能用它当标准答案。实际 production outputs 的字节身份仅用于确定当前交付版本。
2. **原件和 as-of 训练（h1）**：仅从 `runs/R21/inputs/raw/` 构建原始表、来源行号/hash、精确重复折叠、修订冲突/到达单调性、日期/维度/有限值与单位审计。按各原点 `available_at <= origin` 选最高已公布版本，并严格排除服务日期未早于原点日的标签。独立建训练与169列特征后，逐项和获准的 R21 source train/train-features/promotion-source 文件核对；未来标签绝不回流训练。
3. **策略与来源残差（h2）**：独立构造共享无截距 Ridge(alpha=10) 的固定169列及近56日同店品星期均值回退策略，不改策略和参数。对 residual_coordinates_all 的来源训练快照、特征/系数/point 轨迹逐源重建，匹配 raw 的11月4日最高成熟版本、raw row/hash 和其真实到达时点。误差只由成熟原始 demand 减去 source trace 的10位发表 point 重算；不以 `error` 为真值。严格要求来源原点早于目标原点、服务日已结束、实际使用的成熟版本已到达，以及该日期96个坐标全齐；同源14日窗的另一日未就绪不剔除当前合格日。只取每个日期一次。目标窗不得成为残差样本。
4. **完整策略回放（h3）**：每个固定原点/策略独立生成4032唯一键的点、90%区间、实数情景和整数行动。区间来自完整日误差情景 `max(point+error,0)` 的线性5%/95%分位并四舍五入10位。边际MILP以缺货+报废期望损失为唯一目标，资源分别逐日约束；保存完整求解状态、界、gap和直接复算目标。逐键与 production 的对应 artifact 比较，但结论以 raw 独立重建为准。逐窗报告 MAE/RMSE/bias/覆盖/上下漏出/宽度/interval score/缺货/报废/损失/采购/件数；完成1–14与15–42、六个7日带、活动、活动×步长、12店、8品、日配对路线差。空活动格显式保留零日期/零键和 `not_estimable`。前两窗合计只作84天描述；第三窗和第二窗重叠25天，单独陈述端点压力，不能混成独立样本或给显著性/因果/覆盖保证。
5. **独立边界（h4）**：真实执行 3键穷举小oracle与MILP目标比较；晚1秒修订可见性；95/96坐标；同窗一日合格、一日缺一坐标/晚到时的逐日保留；合法非整数需求情景；非有限/负预测或情景、非法整数行动、单键/总资源超限。点预测无需落入偏差区间。边界输入、结果与命令收据单独保存，不引用作者内嵌 tests 输出。
6. **clean rerun 与差异（h5）**：在独立重建之后用作者显式 `--raw/--config/--newout` 入口写到全新 `review/initial/clean-rerun/`。比较逐键、情景/残差成员、求解目标/可行性、所有分组的语义和数值，而不把同源复跑当独立证据；该入口不得写入锁定原交付。保持初次首判差异和任何运行错误的原收据。
7. **报告与PDF消费者查看（h6）**：读完整 `report-v1/REPORT.md`，与独立数据/源计算逐数值核对；先阅读 R22 报告构建源码 `source/build_report_v1.py` 以建立图表生成追踪，不读禁止的 author_checks/finalize/diagnostic 源。对最终13页 PDF 做元数据和页数读取、完整文本抽取，再逐页完整渲染成PNG；每一页都用 `view_image` 实际查看，记录页码/页数，细看表格、图例、字号、中文字体、页码、公式、单位和图表轴。缩略总览/文本抽取不能代替逐页视觉检查。正文/附录和图表逐项与独立表及原件核对；页面有任何更改则重渲染并再次全页检查。PDF只读，不创建或编辑，不调用 artifact marker。
