# 独立审查中的论文质量诊断

本文件解释冻结acceptance.json中的六个quality_diagnosis维度，不增加必需模型数量、固定页数、虚构分数或获奖预测；不发给构建者或执行者。它在任何论文执行前保存，不能在看到结果后改成有利于某层的标准。

每项用 achieved / partial / missing，给出实际证据、可能改变结论的缺口和最有价值的下一动作。先判断a1–a6是否存在实质失败，再诊断质量；格式完整和数值可行并不足以自动达到以下充分状态。

| 维度 | 充分状态的可观察证据 | 常见不足的实际表现 |
| --- | --- | --- |
| 题意与问题链 | 每个原目标有直接答案；有冲突的目标用明确且合理的权衡表达；约束解释与题面一致，数据不足只产生有边界的结论 | 把多目标改为一个方便指标；少做原题一问；附件缺字段时凭空补齐 |
| 数学与方法依据 | 假设及其后果明确，选择由问题结构/数据或实验支持；比简单替代法的收益或成本有证据；关键物理/统计条件进入求解和核查 | 罗列模型名称；只给启发式坐标而不解释选择；复杂度增加却没有收益依据 |
| 实验与反证充分性 | 比较针对影响原结论的弱点；优化时尽可能给有效界与候选质量，无法给界时准确解释未知；参数/边界/通用性实验能改变或限定真实结论 | 单一可行结果直接宣布完成；只做文件存在检查；敏感性仅换数字而不解释结果；大规模验证与原场景输入口径不同却直接比较 |
| 可复现与跨产物一致 | 从原件到结果的实际重跑；关键约束/目标独立复算；论文主表、图和结论能定位到运行产物与配置 | 论文值来自手填常量；只重复作者检查器；图表无法追溯；正文与CSV不一致 |
| 科学论证与表达 | 独立读者能理解问题、公式、方法和结果；摘要给支持的发现，图表回答具体问题；结论讨论实际意义与适用条件 | 日志式报告冒充论文；章节齐全但只有方法简介；无结果解释；图表只是装饰 |
| 工作流迁移与自主补缺 | 新执行者无需设计者私有解释即可执行关键分支和交接；它识别并弥补重要证据缺口，smoke通过后仍推进完整交付 | 只有阶段名/角色名；执行者靠根协调者追加解题标准；把早期片段或自检当完整独立验收 |

如完整paper已生成但任何维度仍partial/missing，报告“论文已产出，质量仍有具体缺口”，列明不足；不能因为产出文件而宣称全部充分。一次单题诊断不能判断通用能力或层级因果优劣。独立首审与收到反馈后的复审分别记录。
