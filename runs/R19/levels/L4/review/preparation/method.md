# L4 独立验收准备方法

本方法冻结于正式生产交接之前。当前未读取执行域、生产论文、生产结果或其他人的判定；没有生产验收结论。来源为 L4 原输入、C11 Forge、L4 冻结设计、三份官方原件及冻结评价文件。设计自报检查只用于理解接口，不作真值。协调者未给期待答案或排名。本次不求解完整题目、不联网、不安装、不另派 agent。

## 原件核查与接收顺序

`source-audit.json` 保留逐页 PDF 文本、DOCX 全段落/表格和原 XML、XLSX 三张表所有非空原值/类型/缓存/格式/合并范围，以及原件、评价、设计锁的逐文件实算身份。实际 PDF 三页已全部渲染并阅读。DOCX 22 段和 1 张 6 行表已直接读取；XLSX 两业务表和空 Sheet3 已完整遍历。没有用设计转录替代原件。`source-contract.json` 从原 DOCX 解析车型/货物字段，从原 XLSX 解析产品 mm 区间和来源。未计算完整题最优解、车辆组合、候选排名。

正式接收只在协调者明确授权具体冻结生产目录/生产锁后开始。先复核现有原件和评价/设计锁，再核对交接清单与逐文件生产锁（相对工作根 path/size_bytes/sha256），拒绝把未冻结的新文件偷偷补入首审。记录生产身份、首次独立首审和实际授权边界；任何后续有反馈的复审另标 informed。生产包可以包含作者自检与失败记录，但按原件和实际计算判定，作者 pass、退出码和文件存在均不建立正确性。接收后先列实际材料和缺项，再阅读假设/代码/结果/论文；不先读作者的预期结论来选择测试。

## 独立几何、支撑、承载及指标计算

正式阶段用独立适配器把生产坐标转换为 `independent_checks.py` 的规范接口，不调用作者合法标志或作者检查器充当真值。适配只能做字段/单位转换；原尺寸、重量、数量、车型额定载重、费用必须绑定 `source-contract.json`。坐标轴应可从右后下解释；如作者采用另一个等价轴向，验证变换及图文一致性后检查。所有数值有限、尺寸与重量正、ID 唯一；逐类型库存与原件精确对照。单车允许未装，但不得超库存；整批库存必须全且仅一次，重复 ID 和重复模式展开不能隐藏多装或漏装。

几何全量检查每车每件边界及每一可能相交对。正体积相交拒绝，边界接触允许；车顶余量至少3cm。校验器使用 1e-7cm 数值容差，原整数 cm 可做精确交叉复核；不得把容差扩大吞掉实质越界/安全差额。货物放置三边必须为原三边允许排列，标准件任意正交排列；G4/G5 按唯一原长宽高顺序。易碎方向题面未明，应看作者公开解释，不能凭空禁全部旋转。物品维度不能任意改变，即使体积相同。

支撑由坐标重建，忽略作者 support_ids 的真假，另比较作者记录是否一致。底部接触地板，或上下面 z 等高且水平接触面积为正。对易碎件，底面必须完整被地板或标准件顶面覆盖；矩形并集用 x 分段求 union 面积，不用面积简单相加掩盖重叠/孔洞。易碎顶面禁止再载（单层不可堆叠的默认解释）；“全车同一层高”的更严格语义不是自动新增必需约束，若可能改变推荐则要求边界/敏感性。普通/定向件悬空不能形成稳定可落地方案；全底支撑属于设计声明的保守假设，需检查是否符合作者选择，不能把它未经说明升级为题面唯一语义。

定向件姿态固定；其直接上层箱均质中心投影与下层闭矩形对照。均质假设未获实测重心数据支持时要限制物理推论。多支撑下逐承载件中心要求是保守分支，不用一个跨空隙凸包作为原句已满足的证明；不同合理解释必须公开和有后果分析。正式检测发生严格分支拒绝时，区分官方强约束违约、作者自选语义违约、解释不确定性，不混淆为统一 fail。

承重必须包括沿支撑链传下的上层自重和其所承载载荷。单支撑链先手算，不能只检查每一邻层单重。多支撑独立建立静力可行 LP：接触矩形角点的非负竖向反力（kg 等效），每件满足竖向平衡和 x/y 一阶力矩平衡，上下作用相反；地板承接全载且不套货物承重阈值。每个下层件上收到的外载总和不超过 500*其顶面积/10000，另以实际接触并集面积作保守压力语义分支。LP 单次 10 秒，只用于独立验证静态承载存在性，不进行完整题求解；超时/数值异常写未验证，不能当物理可行。非负力及平衡残差检查，选关键链/多支撑手算交叉核实。面积 kg/cm² 与 kg/m² 不能差 10000 倍。此模型不证明材料局部应力、非均质物品、摩擦或路上振动认证。

逐车独立 UV=sum原物品体积/(L*W*H)，UW=sum原重量/额定载重。H-3 可装体积率单独命名，不能冒充原满容率。整批 UV=sum体积/sum原车厢体积，UW=sum重量/sum载重，不能简单平均各车率。总车辆和车型数从实际 truck_id/type 求出，总费用从原费率重算。空车/重复车、遗漏单车输出、各种场景混表均须显式检查。

## 优化证据与合理性

正式阶段按原数据独立计算必要的总重/体积松弛界，不在准备期预填数字。单车型向上取整界，混合车型用总重/体积非负整数覆盖车数/成本松弛；体积可用安全高度松弛但要说明有效性。自选受限模式 LP 的值不是原问题合法下界；忽略约束所得候选不可充可行上界。下界闭合或有效证明才支持最优；启发式可行解应给界与 gap，得不到界就说明未知。输出 solver optimal 只能证明其实际所解模型，不自动证明原题。

L4要求重要问题尽量有简单 baseline、经典方法及可能改进。不强加三套获益或固定模型数量；实际方法必须有机制、同输入/约束/预算的公平比较，或有可信的不能采用原因。看合理性、效果、稳定性、可解释性、计算成本、原目标满足情况；比较规则不能事后挑有利口径。性能/参数实验需实测、重新求解并解释瓶颈与目标变化；只重算原方案利用率不能证明重新优化效果。随机法核查 seed、重复和失败/超时保留，确定法不强加随机重复配额。选择针对实际弱点的反证/边界/机制对比，不以模型名或文件数代替证据。无真实改善可保留简单方法；结论不超证据。

附件2产品尺寸为 mm、车为 m，统一 cm 时分别除10/乘100；化验与仓测不当独立大样本。区间上界物品、下界闭合箱体是保守几何分支，名义尺寸与缺化验选源另标。商品规格中的 L 数字不是货物几何尺寸或重量。原表无数量/单重/类别/载重/完整费用语义；不把合成填充称实测补全。E3为公路元/1000km，铁路/海运 E4:E6文本与无独立表头 F4:F6不能直接当元/趟；距离未知不可实际成本推断。高低板与栏板高度不得静默套闭矩形内高。已有几何/区间/公开合成压力测试可以有边界地支持机制通用性，不支持完整真实运输最优/成本结论。

## 复跑与论文实际阅读

获授权后在审查写域清洁输出中按说明跑代码，输入从官方原件重建/核对，保存命令、返回码、真实耗时和输出身份；不覆盖冻结生产包。程序要实际计算而非复制固定答案。选择原件数量、车辆载重或尺寸小变体检验输入驱动与异常输入；变体明确合成并隔离。一次小路径成功不替代全量场景复跑。作者校验器可用于理解接口，但重要约束和目标仍从坐标/原件独立复算。非确定法比较可行性、目标与合理统计差异，不要求逐字坐标相同；固定 seed 的变化要解释。

逐字实际阅读完整最终中文稿，包含正文、公式、每个结果表图、摘要、结论、附录及管理者报告。不是用字符数、中文率、章节名或文件存在判 a5。读者必须能恢复问题、变量单位、假设后果、模型为何合适、算法怎样执行、每题数值答案、验证结果为何合理、企业如何按条件使用。公式索引/目标/约束须与代码一致，不能模型简介加日志冒充完整论文；图表应回答具体问题，有单位、图例、来源和文字解释。摘要与结论应陈述被结果支持的发现，讨论适用条件和材料缺口。排版/语言可理解性与数学及科学论证分别记录，不因流畅语言掩盖实质缺失。

建立论文关键主张到原件→配置→代码→运行输出→表图/正文的逐项追溯；主结果表、车辆数/成本/利用率、参数图和最优/改善/稳健性结论均核对，不能只抽第一张表。最终稿若为 Markdown，实际打开/阅读且检查链接图片、公式和中文；如 PDF/DOCX，使用已有库/渲染核对完整页及可读性。版式工具不可用不替代内容判断，也不假称已验证。参考来源应为实际读过的原材料，未知外部标准/比赛规则不编造；本离线练习不宣称已核实正式比赛规则。

## a1–a6及六维判断冻结

| 必需项 | 可观察证据与拒绝依据 |
| --- | --- |
| a1 | 上述所有原题行实际回答且提供方案/程序/报告。缺原题一问、无逐件方案、改目标、伪补数据或约束遗漏属实质不满足；合理歧义须公开并有边界。 |
| a2 | 原值单位绑定、共享约束、数学假设后果、算法选择和参数出处有论证；关键物理条件进入求解及检查，比较公平。只命名模型不构成数学依据。 |
| a3 | 清洁原件重跑、独立可行性/目标重算、论文追溯实际执行；硬编码答案、造执行、只重复作者检查器不能通过。不可用证据记未验证。 |
| a4 | 对任务弱点的实际小反例/边界、方案质量界或诚实未知、参数性能和方法比较证据。缺失实质检查/把可行当最优/只文件检查不能通过。 |
| a5 | 实际全文阅读判断中文独立科学论证是否完整；公式结果图表与原件代码吻合，结论克制。有文件但日志式稿/无结果解释/未回答原目标不能通过。 |
| a6 | 新执行者依设计实际完成接收分支、识别证据缺口并修复；smoke和full职责分离，角色/失败真实记录，无设计者私有解释。设计有步骤不自动证明可迁移。 |

每个必需项正式阶段给 evidence-backed pass/fail/unverified（可用词需与最终接口适配），写源定位、产物定位、实际观察、限制与最有价值下一动作；准备期全为 not_evaluated/null。实质必需失败不被均值、漂亮论文或其他成功项抵消。

六维仅用 achieved / partial / missing，与冻结 quality-diagnosis 定义逐项对照：题意与问题链；数学与方法依据；实验与反证充分性；可复现与跨产物一致；科学论证与表达；工作流迁移与自主补缺。每维实际证据、能改变结论的缺口、下一动作。论文存在仍可质量 partial/missing。缺完整链不能因文件齐全判 achieved；不设置页数、模型数、猜测分数、奖项或跨层优劣。
