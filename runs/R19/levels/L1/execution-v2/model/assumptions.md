# 模型版本3.0及冻结解释

坐标：右后下为原点；x向车前、y向车左、z向上，cm。每件给最小坐标角与轴置换。

1. 允许标准件六个轴置换，定向件保持原姿态；易碎件主口径保持原姿态，水平旋转另作场景。
2. 所有货物全底面支撑，不悬空。易碎件可由共面标准件顶面并集完全覆盖；不允许任何货物压易碎件。不要求全车易碎件处于同一z高度；每条竖直射线至多遇到一个易碎件。
3. 定向件作为直接支撑时，每一个与之有正接触面积的上箱自身重心投影需在其闭投影矩形内；边缘重心允许，未提供抗倾覆裕度。另核算累计上方传载的合成重心。多支撑的反力区为各接触交集。
4. 自身质量均匀分布于箱体底面，上方接触压力沿竖直方向原位传递，不作横向重分配。所有支撑全覆盖使每个平面分区形成无间隙竖直链；各点反力非负，总力与x/y方向重力矩逐层守恒。每箱上方每个接触点压力≤500 kg/m²（不含自身质量）。这比仅平均接触压强更严格；同时报告受力面积均值及整顶面积均值。没有弹性/强度分布和动态加速度资料，故它是明确的静态可行口径，不是道路动态稳定保证。
5. 正交刚性箱不碰撞，触面允许；顶面≤车高−3cm；利用率主分母仍原车体积。
6. 所有全批次解数量3000件恰一次，Q1单车可留库存；同车数比较成本、同成本比较车数仅为选推荐的次级偏好。
7. 5cm高度图是本题边长公因子构造搜索空间；标准件可以跨多个完整共面支撑，但定向支撑仍执行第3条。它不是三维连续几何完备求解。本文只声称可行上界与所搜候选非支配，不声称全局最优。
8. 参数场景按configs/experiments.json直接修改真实尺寸/质量/数量并重算；货物尺寸各轴±5cm，车厢尺寸各轴±10cm，均为管理情景而非官方数据修订。附件2缺质量、数量、类别、载重和可换算趟费用，只做真实尺寸区间几何接口。
