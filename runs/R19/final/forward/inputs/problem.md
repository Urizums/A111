# 小批次运输装箱（自建离线验证材料）

将raw.json的全部货物运输完成，决定使用车辆数、总费用和每件实际坐标；车辆同型且不限辆数，先最少车，再最小费用。给出数学模型、可行解、必要的结果验证、解释及完整中文技术论文和可运行程序。结果应能由该原始数据重新计算。没有外部比赛投稿或现场安全认证。

所有数据单位见字段名，货物都是刚性长方体，固定给定方向；不能转向。每件ID由types内item_ids给出，类别、尺寸和单件质量以本原件为准。车辆内尺寸为实际长宽高，货物不得越界、重叠、遗漏或重复，总质量不超过载重；顶部须留clearance_m高度间隙。

物件可直接落地，或由一个下层物件完整支撑其底面，支撑接触高度相等。采用均匀质量及静态竖直载荷假设。上层质量连同其继续承受的全部外载传给下层：standard的累计外载除顶面面积不得超过standard_limit_kg_per_m2。fragile只能落地或放在standard顶面，顶面不可承受任何货物；同一高度仅水平相邻不算支撑。输出中附带的类别等标签不能更改原件身份。只研究这些已给定条件，未知的车辆轴载、道路振动和装卸通道不填造为实测。

最终论文交付PDF与可编辑中文源文，供独立读者查看；这是文件格式要求，不是篇幅配额。
