# 从实际结果到完整中文论文

论文角色由执行者承担，并由接收角色检查。模型作者不能把结果表交给“以后某人润色”而结束原题。先按问题建立claim registry，最后所有核心主张都有真实结果和来源；未完成实验保持pending，不能填想象数字。

下列是内容责任，不是固定章数/篇幅。可按科学叙述合并章节。

| 内容 | 接收证据/必须解释 |
|---|---|
| 题目、摘要、关键词 | 原创合成离线题；9/30 18:00一次性14日；摘要在结果完成后写，报告真实主要结论与限制 |
| 问题、口径、假设、符号 | 需求不是结算收入；北京时间、版本/到达、需求件与元/件、无结转/流失；每假设的原因和失效后果 |
| 数据与规律 | 审计和具体图表；重复/缺失/迟到修订、可知快照；店/品/日期规律，相关与因果边界 |
| 预测模型与选模 | 实际可运行方程/参数、特征来源、非负/缺失处理；基线与选定方法的理由及真实比较；一次14天可知信息限制 |
| 不确定性 | 方法、校准/覆盖/宽度、步长/组别弱点；历史天气不足14日、假期2天到7天外推，不夸大保证 |
| 备货模型/求解 | 原损失公式、整数上限和每日双约束；预测如何变q；目标不加采购；可行性/solver最优性证据及未知gap |
| 实验设计与结果 | 冻结时间划分/原点、later labels评价口径、指标/比较资源/seed；每道题真实结果、主要数字、失败或无改进也解释 |
| 可靠性、资源及取舍 | 缺货vs浪费、容量vs金额、按店品分配及边际解释；压力/敏感性在原约束外的试验标清，未来收益无真值 |
| 结论与适用边界 | 回答全部原题、可执行最终方案的范围；误差/迁移/合成数据与实际业务差异，不保证奖项 |
| 引用及复现附录 | 真正用过并核实来源，或没有外部来源如实；入口、依赖、seed、配置、表定义及hash；日志无需占满正文 |

图表每个都需“待答问题→数据/计算→图形→解释→限制”。不要预设固定图数；可以用需求规律、按步长误差、区间覆盖、逐日资源与slack、取舍曲线等适当图回答具体问题。中文字体、横纵轴、单位、图例、标题/图注清楚；若展示未来，说明预测或情景。大表置附件/摘要，论文突出解释，不能只展示模型名和排行榜。

生成图的底表、绘图代码和每个claim来源可重跑。论文中的表格可从结果程序生成，避免手工抄数。重写或翻译后逐项核对数字、符号、变量定义、成本及结论强度；中文表述若使读者无法重建方法或误解未来收益，是实质缺陷。

## 交付包与最终格式

原题没有指定模板或页数。可逆默认是完整中文可编辑Markdown源稿+正式PDF+UTF-8机器CSV及程序；若采用Word/LaTeX/其他源稿，由实际工具能力决定并记录。不强制论文使用某库；需先探测中文字体、公式/表格渲染及导出能力。源稿正确不代表PDF正确，接收者必须逐页查看最终导出并重算关键值。能力不可用则报告“稿件已生成、最终渲染未验证”，不能当终验通过。

建议文件职责（执行根由协调者分配，可替换名称但接口不可失）：

- `README.md`：原题与输入定位、实际依赖版本、原件到最终产物的一条主入口、所需资源、输出解释、失败恢复、限制。
- `src/`+`config/`：生产代码与冻结配置；`run`入口从raw生成audit、实验、预测、备货、图和论文，不读取设计smoke结果作为答案。
- `results/future_predictions.csv`、`future_replenishment.csv`：两个独立1344行完整表；`uncertainty/`存区间/分布及说明；`metrics/`、`decision_summary.csv`存证据。
- `figures/`：真实图、底表来源；`paper/`：完整中文源稿与最终渲染稿；`evidence/`：命令原始记录、接收报告和clean rerun对比；`manifest.json`：实际产物hash。

清洁重跑在新的输出目录，不删除原始失败；记录实际begin/end/stdout/stderr/returncode，抽查或全量对比数值与键，允许预声明容差。最终稿与表必须来自同一冻结版本。正式提交、发布、外部联系不在本离线授权范围。
