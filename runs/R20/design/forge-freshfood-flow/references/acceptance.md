# 原要求、可证据化断言与责任

本表是流程内原题接收要求，不是额外赛题评分提示。冻结后修缺陷，不因失败降低标准。全部值域在sum/比较前核对；NaN/Inf不能绕过约束。未提供未来真值，任何验收都不支持未来实测收益或获奖概率。

| Gate / 对应原要求 | 输入/断言及证据 | checker及reject条件 | 失败路线与结论边界 |
|---|---|---|---|
| P0 可尝试 | 原件hash、实际Python/库/solver/中文渲染版本或未知，原题与decision一致；命令起止输出 | 执行者；缺必要材料/能力需标明未准备 | 改合法可逆路径或局部blocked；仅preflight不证明完成 |
| P1 口径/可靠性 Q1 | raw与snapshot；晚到行/重复/版本/空值/训练与评价用途实际重建；原点前所有输入可追踪 | 数据接收角色；目标日期settlement、未来天气实况、晚到修订进训练即reject | 修快照/特征并重算受影响实验；不能只修论文措辞 |
| S0 有限路径 | 从真实raw到选定小scope预测、q、接收和用户相关解释；late信息或非法q实际被拒；数值重算 | 自检可做但标明；不存在可行表/误把非法值接受即reject | 仅该scope可运行，不支持预测优越/最优/全题完成；全量gate仍待执行 |
| A1 完整预测 Q1/Q3 | 1344键精确完整无重复，点预测有限非负；不确定性level/区间或分布、校准与外推限制；历史实验误差与原点可用性 | 新验收者；错键/缺键/未来输入/区间无依据或当实测未来即reject | 修数据/模型/区间接口；未来覆盖仍不可实测验收 |
| A2 正确整数备货 Q2/Q3 | 原items/decision与最终q独立读入，逐日sum量、金额、上限；值域；目标按原式重算、采购只约束；小例oracle/求解状态 | 新验收者；小数/非有限/负/超限、重复成本、错单位即reject | 修优化并复核全部日；可行非最优要保留状态/gap，不能发明最优 |
| A3 可靠性与资源取舍 Q2 | 同信息同验证的预测/备货对比，损失分项与资源分配、slack；选定风险敏感性/迁移假设与影响有真实结果 | 研究接收/新验收者；没有可靠性证据或用不同信息比较称改进即reject | 冻结合理比较后补算；原题不要求所有模型/额外公平约束 |
| A4 科学论证与中文论文 Q1–3 | 独立可读完整论文；方程/变量/假设/选模/真实实验/图表解释/结论局限；claim-to-result-to-raw抽查关键数字和所有答案 | 新验收者；占位稿、结论无证据、漏问、因果/未来收益越界、关键意思含混即reject | 修论证或补证据，不仅润色；文采偏好不能变必需项 |
| A5 程序重跑 Q3 | 从原件、冻结代码/config/依赖/seed，在干净输出目录一次生成全量表、图与论文；命令及数值比较 | 新验收者/复现角色；手工隐藏修表、脚本不从raw、数值/键不符即reject | 保留旧结果与错误，修复受影响链重跑；文件存在/exit0不足 |
| D0 最终格式 Q3 | 最终机器表可读，中文渲染文档逐页查看；公式、表头、图例、单位、关键数字、引用一致；artifact hashes与说明 | 论文接收角色/协调者；导出丢字、公式损坏/截断、数字不一致即reject | 修渲染或源稿；若缺必要工具则保留源稿但最终格式未验证 |

最终验收包给原题、原件、真实产物、代码/配置/环境与重跑入口。不提供预期模型排名、作者诊断、旧验收结论或意图答案。验收者逐要求返回 verdict（pass/fail/unverified）、原来源、实际检查、证据路径、范围限制。作者报告仅供核对，不替代观察。一个上下文换角色仍是自检；没有可用独立者则记录此限制，不自称独立通过。

受影响修复后重新检查原assertion，保留旧失败和总次数；无统一两次上限。optional建议须分开，不把增加模型/字数/引用数量当原题必须。验收者不能因省事从完整性要求退到目录或单日smoke；所有未覆盖要求留在backlog。
