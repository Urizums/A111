# R20 冻结生产后的独立接收任务

本任务只在执行者停止写入、完整生产字节锁实际建立后启动。当前不是正式验收启动证据。沿用同一独立接收者与既有准备历史，不换人、清除失败或降低五门要求。

只读原始 `inputs/`、`input-lock.json`、外部冻结 `evaluation/ACCEPTANCE.md`、既有接收准备、本次冻结工作流五份文档及 HANDOFF、冻结执行版本的实际源代码/config/README/交付 CSV/图/完整中文论文/PDF及生产锁。完整命令记录可用于核查真实运行；作者诊断、自检判定、旧试验论文和协调者研究结论不提供为答案。不因作者宣称通过省略重算。

写新域 `runs/R20/review/initial/`。从原 raw 实际运行被冻结入口到新输出目录，保留完整开始/结束/退出和产物身份。自行重建原点可用性与历史评价来源，公平检查固定 14 日预测、主要指标、基线、至少一项主要实验、预测到整数计划及原式损失；核验全部未来组合与每日资源。使用真实消费路径执行合法/非法控制，不把准备夹具的自检追认为生产通过。原始公式和物理有限值优先于输出标签。

首次生产冻结后方可读取 `evaluation/holdout_truth.csv`，只评估锁定版本；不要回传真值/预期排名给执行者或以留出集选模。之后若反馈缺陷并修订，保留首次版本与首判，复查明确为知情；同一留出数据不能再次称未见测试。

全文阅读中文论文并实际渲染、逐页查看最终 PDF。检查核心定义、单位、公式、主表/图的数据来源与含义、实质研究论证、不确定性及结论边界。语言改变或遮蔽科学含义属于实质问题；可选文风建议单独列出。没有模型/页数配额、奖项或官方参赛合规认证。

每项 d1–d5 给出判定、原问依据、实际来源/产物身份、执行观察与限制；未检查标 unverified，原始失败保留。报告与 JSON 首判必须在反馈作者前冻结。所有实际进程终态后保存 manifest 和 checkpoint，停止写入并通知 root。模型/token/cost 未实测写 null。
