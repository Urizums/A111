# C3 补充协议 v1：UI 证据与脚本边界

适用于 C3 后续任务；不修改已冻结的 C3 源码或重评分历史试验。

1. 在执行前冻结原旅程、原数据、目标源码及验证者写域。真实产品响应、受控延迟、模拟服务各自标明。
2. 对会改变过滤条件结果的操作，以原产品规则验证消失或保留，不能要求已转为处理中记录继续留在“待处理”列表。
3. 保持目标 CSP；使用 locator/可观察状态等待。验证脚本不能为了执行字符串轮询而降低产品安全策略。
4. 独立脚本最多两次修正；耗尽后保留失败和未执行项，关闭该验证分支。禁止换脚本/样本/worker 伪造独立通过。
5. 作者对未执行产品状态的额外观察必须单独保存原输入身份、归属和范围，不修复或重跑已耗尽脚本，不提升独立结论。目标需求证据与独立验收完整性分别报告。
6. 浏览器实际动作、后端 HTTP、截图视觉检查分别归档。截图不能证明提交成功；API 成功不能证明键盘、冲突文案或布局。
