# Meta-Agent / Agent Flow 设计方法研究：已知机制与可发展架构

## 研究对象边界

Forge 有两种互补交付物，不能混成一份 Skill：

- **方法层（portable Skill）**：如何分析目标、选择分支、设计流程、定义交接和验收、根据证据修复。C13/C14 九 Markdown 均属此类。允许依宿主工具手工/由 Agent 使用，不声称内置调度器。
- **执行与研究层（host runtime / harness）**：实际调用 Agent/命令/浏览器/文件、状态与 lease、幂等、恢复、回执、独立评测、CI。已有仓库 CLI/脚本优先复用；新增适配器仅解决经实测确定的缺口。不能把它偷偷作为 Skill 运行依赖。

## 从目标生成工作流：七个决策，而不是七个固定阶段

| 决策 | 输入 | 选择依据 | 最小输出 | 容易犯错 |
| --- | --- | --- | --- | --- |
| 1 交付分流 | 原始目标、现有材料、受众 | 单次结果/完整软件/重复方法/已有包调用 | 本次交付定义 | 小事硬造 factory |
| 2 要求分级 | 明确要求、必要推导、真实许可 | 不做会使哪项原目标无法达成；触发条件是什么 | 必须/条件/可选/未知 | 偏好变成强制拒收 |
| 3 结果实例 | 方法、对象、时间、版本等原任务要求的维度 | 原问题要求的每个结果都要有生产/消费位置 | 目标→产物/接口映射 | 只给 selected，漏其他方法 |
| 4 依赖与角色 | 操作之间的数据依赖、并行价值、实际能力 | 单上下文够用则不分；独立性或工作量要求才引入角色 | 有向步骤和所有者 | 固定多 Agent 阵容 |
| 5 工具和接口 | 环境、版本、权限、数据模式、错误分支 | 可执行、可验证、可恢复 | 输入/输出/状态/重试条件 | 幻想 host 具备某 API |
| 6 接收证据 | 原要求、原材料、风险、运行输出 | 哪个 observable assertion 能真正拒绝错误 | smoke + 完整验收范围 | exit0/截图替代真实效果 |
| 7 有界改进 | 失败事实、反例、剩余资源 | 只有具体变化/新信息能检验才再试 | 修订和对照记录或停止 | 重复无信息动作、改写旧门 |

这是审视工作流的决策视角，不要求把每一行都做成文件或由独立 Agent 完成。简单任务可直接返回结果及轻量核验。

## 面向执行者的工作流合同（推荐字段，不固定格式）

- 目标与使用者：做什么、最终产物被谁消费。
- 资料与时间：原材料位置/版本、读取权限、何时可用、未知是否阻塞。
- 节点：触发条件、实际操作、owner/host 实权、输入/输出模式、下游消费者。
- 接收接口：源字段、单位/时区/版本、必要断言、拒绝反例、证据所在。
- 异常路由：可恢复还是权限/资源阻塞；重试是否幂等；如何避免重复外部副作用。
- 验收边界：自检、执行成功、独立接收和推广结论明确区分。
- 下一动作：只在完成前置依赖且目标仍有效时进入，不因 TODO 末项而自动启动无意义新阶段。

触发条件或不确定性不改变结果的字段可以省略；必须保障消费者可用，而非强制 JSON 或大量单独文档。

## 交接与独立性

设计者给执行者：相关原始要求、实际工具范围、接口、原数据/来源、必要边界、不透露隐含答案。执行者给消费者：真实产物、配置、版本、源映射、可复现入口和已知限制。独立接收者：只收原要求、原材料和需验证的实际产物，不能通过日志 argv、历史摘要、链接到作者诊断的目录或“预期数字”间接获知答案。若 host 无法控制可见历史，独立性必须标未知/知情。

## 真正的 smoke 是切片，不是漂亮报告

切片应经过关键的真实接口：原始输入→主要行为/数值→消费者检查；触发一个与该断言有关的失败/边界。复杂图形必须在被允许的真实浏览器里点击、键盘走通、检查状态与视口；算法必须从原问题核目标/约束。小 smoke 不承担全范围验收。已声称测量的条件必须在测试数据里被实际激活。

## 科学/文档语义的守恒

当同一核心结果跨源码、CSV、图、正文与 PDF 流转时，冻结源、单位、版本、运算次序、舍入与显示约定，并在读者看到的终稿上核对。复杂产物可用机器化事实表；单次答案用直接重算即可。论文的语言问题按是否影响定义、理由、假设或结论强度判断；文风偏好不应自动升级为实质失败。

## 学习机制的真正研究问题

单独追加一句“必须检查 X”可能不会改变行为。研究重点转成：在哪一步以何种数据结构或负例，使 Agent 不遗漏原要求；何时决定求助子 Agent；能否识别反馈来自合同/数值/宿主/验证器；如何压缩为下次可用的决策规则。每个新机制应能展示失败反例和成本/负担，而非只展示规范更长。
