# 原创生鲜网络42日规划题

所有数据是虚构离线案例。12店各有8品，在2026-10-31 18:00（Asia/Shanghai）为11-01至12-12共42日作固定计划，期间不看新需求调整。每个店品每日0至55件整数、全网络每日1600件上限、6000元采购预算。没有结转库存，需求超出备货为流失，过量为报废；每品单位采购、缺货与报废金额见items.csv。最小化两项损失，采购费只约束预算。

1. 理解附件和可用信息：日期/店/品是键，需求有公布时点和版本；重复出口不是新需求，迟到修订不是当时已知。holiday列指虚构业务活动，不是官方节日；天气/促销需要核对各自公布时点。说明异常、缺失、单位及限制。
2. 对4032个未来键给出点预测和名义90%区间，说明如何建立、选择、验证方法，说明活动与预测步长差异是否可分辨以及边界。
3. 给出同键整数备货，每日约束和损失定义准确，比较现方案政策与自己认为值得检验的替代。现方案算法与迁移约定见reference/BASELINE.md；在新历史上拟合，不移用旧结果。各路线保持同信息、同资源和同目标，不能先见未来真值选路。
4. 用历史可得条件做实质实验，保存选路/校准/验证边界、代码配置、原件来源与可重现结果。汇总日/活动/步长/店/品差异、区间宽度与漏出权衡、优化或合理性检查及稳健性，避免为了模型数量堆砌方法。
5. 完成科学中文论文与有效图表，解释假设、数据、数学抽象、选择证据、方案、结果、局限及业务意义。论文、图表、计算与逐键计划一致。最终未来真值当前未开放，不能虚构实测覆盖；首锁后另由接收端评价，后见结果附录须明确边界。
