# 成品边界审阅

C8 是方法技能：从目标和验收倒推工作步骤、决策、职责、交接和停止条件；按请求设计、执行或改进流程。
它不要求本仓库、Python、WSL、factory schema、状态控制器或特定模型。普通任务和多角色任务均按实际需要选择方法。

入口保留共享决策与必要条件；四份参考分别用于流程设计、协作、判定和跨会话接续。
所有引用都在成品文件夹内；没有另一个 skill 的强制依赖。`agents/openai.yaml` 是可选 UI 元数据，本版不引入。
没有已证明需要重复执行的具体确定性操作，因此没有增加辅助脚本。仓库原有工具及测试照旧保留，均不进入 C8 包。

重点保留的非显然约束：角色标签不等于独立上下文、写域声明不等于安全隔离；未知调用先核对再创建；
依据原材料和原要求判定，区分可选建议与必需行为；冻结条件，累计修正预算，旧失败不会因新 actor 或改名消失；
后继计划不等于真实首步，独立支线不能代替被阻塞的阶段验收；TODO 不是后台调度器。

相对于 C7 的变化是产品边界，而非证明平台机制不必要或旧测试无价值。
C7 和之前版本仍用于原历史追溯。新旧阶段的性能、软件系统、UI、provider 和恢复保证不得从本版结构检查推导。

作者检查截至 R10-01 只证明五份文档自包含、frontmatter 有效以及旧记录保留。
R10-02 是新请求下的流程设计和批次执行样本，不是重开或替代 R08 approval-CLI 验收。
